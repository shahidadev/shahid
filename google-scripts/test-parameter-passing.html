🧪 URL Parameter Passing Test

Purpose:

This test demonstrates how URL parameters should be passed and received in the deposit page implementation.

Test: URL Parameter Extraction

Example URL:
https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?username=shahid9211&userId=45ab6f42-ab0b-4ca4-913d-166289484f7a

How It Works in Apps Script:

1. Backend (deposit-backend.gs):

function doGet(e) {
  const username = e.parameter.username || '';
  const userId = e.parameter.userId || '';
  
  const template = HtmlService.createTemplateFromFile('deposit-page');
  template.username = username;
  template.userId = userId;
  
  return template.evaluate();
}

2. Frontend (deposit-page.html):

<script>
  const URL_USERNAME = '<?= username ?>';
  const URL_USER_ID = '<?= userId ?>';
  
  // These variables now contain the actual values!
  console.log('Username:', URL_USERNAME);
  console.log('User ID:', URL_USER_ID);
</script>

Current Page Test:

✅ Key Points:

  • URL parameters are passed via ?username=value&userId=value
  • Backend extracts them using e.parameter.username
  • Backend passes to HTML using template variables
  • Frontend receives via scriptlets <?= username ?>
  • No more "Guest" - actual username is displayed immediately
